# 문자열 관찰

---

```latex
문자열 $S$가 주어진다

수뭉이는 문자열을 관찰하는 것을 좋아하기 때문에 대문자, 소문자, 숫자의 개수가 궁금해졌다

수뭉이를 도와 문자열 $S$에 포함된 대문자, 소문자, 숫자의 개수를 각각 구하여라
```

## 입력

---

```latex
첫 번째 줄에는 테스트 케이스의 수 $T(1\leq T\leq 50)$가 주어진다

각 테스트 케이스마다 한 줄에 문자열 $S(1\leq |S|\leq 200,000)$가 주어진다

문자열 $S$는 알파벳 대문자, 알파벳 소문자, 숫자로만 이루어져 있다

모든 테스트 케이스에서 문자열 길이의 합은 $200,000$을 넘지 않는다
```

## 출력

---

```latex
각 테스트 케이스마다, 문자열 $S$에 포함된 대문자, 소문자, 숫자의 개수를 공백으로 구분하여 출력한다
```

## 예제 입력

---

```latex
3
INYRO
kss418
A1bC23d
```

## 예제 출력

---

```latex
5 0 0
0 3 3
2 2 3
```

## 비고

---

```latex
첫 번째 테스트 케이스에서

대문자는 I, N, Y, R, O로 5개이다

소문자와 숫자는 존재하지 않는다

두 번째 테스트 케이스에서

소문자는 k, s, s로 3개이다

숫자는 4, 1, 8로 3개이다

대문자는 존재하지 않는다

세 번째 테스트 케이스에서

대문자는 A, C로 2개이다

소문자는 b, d로 2개이다

숫자는 1, 2, 3으로 3개이다
```
