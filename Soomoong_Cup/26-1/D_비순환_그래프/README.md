# 비순환 그래프

---

```latex
정점의 수가 $N$, 간선의 수가 $M$인 무방향 그래프가 주어진다

사이클이 존재하지 않는 그래프를 비순환 그래프라고 한다

수뭉이는 비순환 그래프를 좋아하기 때문에, 몇 개의 간선을 삭제하여 그래프를 비순환 그래프로 만들려고 한다

그래프를 비순환 그래프로 만들기 위해 삭제해야 하는 간선의 최소 개수를 구하여라
```

# 서브태스크

---

| 번호 | 배점 | 제한 |
| --- | --- | --- |
| 1 | 30 | $1\leq N\leq 1,000, 0\leq M\leq 5,000$, 모든 테스트 케이스에서 $N$의 합은 $2,000$ 이하, $M$의 합은 $10,000$ 이하 |
| 2 | 70 | 추가 제한 사항 없음 |

## 입력

---

```latex
첫 번째 줄에는 테스트 케이스의 수 $T(1\leq T\leq 50)$가 주어진다

각 테스트 케이스의 첫 번째 줄에 정점의 수 $N$과 간선의 개수 $M(1\leq N\leq 200,000, 0\leq M\leq 500,000)$이 주어진다

이후 $M$개의 줄에 각 간선이 연결하는 두 정점 $S, E$가 주어진다
$1\leq S, E \leq N, S \neq E$

무방향 그래프이므로 $(S,E)$와 $(E,S)$는 같은 간선으로 간주하며, 같은 간선이 두 번 이상 주어지지 않는다

모든 테스트 케이스에서 $N$의 합은 $200,000$을 넘지 않으며, $M$의 합은 $500,000$을 넘지 않는다
```

## 출력

---

```latex
각 테스트 케이스마다, 그래프를 비순환 그래프로 만들기 위해 삭제해야 하는 최소 간선 수를 출력한다
```

## 예제 입력

---

```latex
3
4 3
1 2
2 3
3 4
4 4
1 2
2 3
3 1
3 4
7 6
1 2
2 3
3 1
4 5
5 6
6 4
```

## 예제 출력

---

```latex
0
1
2
```

## 비고

---

```
첫 번째 테스트 케이스의 그래프는 이미 비순환 그래프이므로, 삭제해야 하는 간선의 수는 0개이다

두 번째 테스트 케이스의 그래프에는 1-2-3-1 형태의 사이클이 하나 존재한다
이 사이클을 이루는 간선 중 하나를 삭제하면 사이클이 없어지므로, 정답은 1이다

세 번째 테스트 케이스의 그래프에는 1-2-3-1, 4-5-6-4의 두 사이클이 존재한다
각 사이클에서 간선 하나씩을 삭제해야 하므로, 정답은 2이다
```
