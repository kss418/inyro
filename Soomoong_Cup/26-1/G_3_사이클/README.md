# 3 사이클

---

```latex
정점의 수가 $N$인 트리가 주어진다

수뭉이는 트리에 간선 하나를 추가하여 새로운 사이클을 만들어 보려고 한다

서로 다른 두 정점 $u$, $v$를 골라 간선 $(u, v)$를 추가할 수 있으며, 같은 간선이 이미 존재하는 경우에는 추가할 수 없다

트리에 간선 하나를 추가하면 정확히 하나의 사이클이 생긴다

수뭉이는 이렇게 생긴 사이클에 포함된 모든 정점의 차수가 3이 되기를 바란다

여기서 어떤 정점의 차수란 그 정점에 연결된 간선의 개수를 의미한다

이 문제에서 차수는 간선을 추가한 뒤의 그래프에서의 차수이다

조건을 만족하도록 추가할 수 있는 간선의 개수를 구하여라
```

# 서브태스크

---

| 번호 | 배점 | 제한 |
| --- | --- | --- |
| 1 | 30 | $1\leq N\leq 200$, 모든 테스트 케이스에서 $N$의 합은 $300$ 이하 |
| 2 | 70 | 추가 제한 사항 없음 |

## 입력

---

```latex
첫 번째 줄에는 테스트 케이스의 수 $T(1\leq T\leq 50)$가 주어진다

각 테스트 케이스의 첫 번째 줄에 트리의 정점 수 $N(2\leq N\leq 200,000)$이 주어진다

이후 $N-1$개의 줄에 걸쳐 트리의 간선 정보 $u, v(1\leq u, v\leq N)$가 주어진다

주어지는 그래프는 트리임이 보장된다

모든 테스트 케이스에서 $N$의 합은 $200,000$을 넘지 않는다
```

## 출력

---

```latex
각 테스트 케이스마다, 조건을 만족하도록 추가할 수 있는 간선의 개수를 출력한다
```

## 예제 입력

---

```latex
3
7
1 2
1 3
1 4
2 5
3 6
4 7
8
1 2
2 3
3 4
1 5
2 6
3 7
4 8
4
1 2
2 3
3 4
```

## 예제 출력

---

```latex
3
1
0
```

## 비고

---

```latex
첫 번째 테스트 케이스에서 (2, 3), (2, 4), (3, 4)를 추가할 수 있다

예를 들어 (2, 3)을 추가하면 사이클은 2-1-3-2가 된다

이 사이클에 포함된 정점 1, 2, 3의 차수는 모두 3이므로 조건을 만족한다

두 번째 테스트 케이스에서는 (1, 4)만 추가할 수 있다

(1, 4)를 추가하면 사이클은 1-2-3-4-1이 되고, 이 사이클에 포함된 네 정점의 차수는 모두 3이 된다

세 번째 테스트 케이스에서는 어떤 간선을 추가하더라도 생기는 사이클의 모든 정점의 차수를 3으로 만들 수 없다
```
