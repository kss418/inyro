# 수열 매칭

---

```latex
길이가 $N$인 수열 $A$가 주어진다

$N$은 항상 짝수이며, 수열의 모든 원소를 정확히 한 번씩 사용하여 $N/2$개의 쌍으로 나누려고 한다

값이 각각 $x$, $y$인 두 원소를 하나의 쌍으로 묶었을 때, 이 쌍의 차이는 $|x-y|$이다

모든 쌍의 차이의 합을 그 매칭의 값이라고 하자

가능한 매칭 중에서 값의 최솟값과 최댓값을 각각 구하여라
```

## 입력

---

```latex
첫 번째 줄에는 테스트 케이스의 수 $T(1\leq T\leq 50)$가 주어진다

각 테스트 케이스의 첫 번째 줄에 수열의 길이 $N(2\leq N\leq 200,000)$이 주어진다

$N$은 항상 짝수이다

각 테스트 케이스의 두 번째 줄에 수열의 원소 $A_1, A_2, \cdots, A_N(-10,000 \leq A_i \leq 10,000)$이 공백으로 구분되어 주어진다

모든 테스트 케이스에서 $N$의 합은 $200,000$을 넘지 않는다

```

## 출력

---

```latex
각 테스트 케이스마다, 가능한 매칭의 값의 최솟값과 최댓값을 공백으로 구분하여 출력한다
```

## 예제 입력

---

```latex
3
4
1 3 5 9
6
1 1 2 7 10 13
8
-3 0 4 8 9 10 13 17
```

## 예제 출력

---

```latex
6 10
8 26
12 40
```

## 비고

---

```
첫 번째 테스트 케이스에서 가능한 수열 매칭 중 하나는 (1, 3), (5, 9)이며 값은 2 + 4 = 6이다
이는 가능한 최솟값이다

또 다른 매칭인 (1, 9), (3, 5)의 값은 8 + 2 = 10이다
이는 가능한 최댓값이다
```
